# Global AI Jobs 2026 — Power BI Dashboard

## Project Overview
An interactive Power BI dashboard analyzing the global AI job market in 2026. The dashboard explores job opportunities, salary trends, experience levels, employment types, industries, and country-wise distribution.

## Tools & Technologies
- Microsoft Power BI Desktop
- Power Query for data cleaning and transformation
- DAX for data analysis and calculations
- Data visualization and interactive filtering

## Key Insights
- AI job opportunities across countries
- Salary comparisons across roles and experience levels
- Job distribution by specialization and industry
- Employment type and company size analysis

## Project File
- `global AI project.pbix` — Download this file and open it using Microsoft Power BI Desktop to explore the dashboard.
